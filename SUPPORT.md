# Getting help

- Start with [the README](README.md) and [development troubleshooting](docs/development.md).
- Ask a usage or setup question with the [question form](https://github.com/himanshu748/devswarm/issues/new?template=question.yml).
- Report a reproducible defect with the [bug form](https://github.com/himanshu748/devswarm/issues/new?template=bug_report.yml).
- Propose a change with the [feature form](https://github.com/himanshu748/devswarm/issues/new?template=feature_request.yml).
- Report vulnerabilities privately using [SECURITY.md](SECURITY.md).

Include your OS, Node version, commit and sanitized output. Never paste `.env`,
tokens, private prompts, or unsanitized trace exports. This is a community project
with no guaranteed support response time. There is no separate chat or paid
support service currently documented by the project.
