# Code of Conduct

DevSwarm welcomes contributors of every experience level and background.
Treat people with respect across issues, pull requests and project spaces.

## Expected behavior

- Be considerate, patient and specific when giving feedback.
- Critique code and ideas. Explain your reasoning and listen to corrections.
- Respect privacy, identities, accessibility needs and people's time.
- Help newcomers learn, and credit the work of others.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized conduct, personal attacks,
publishing private information without consent, and repeated disruptive or
spam behavior are not acceptable.

## Reporting and enforcement

Report public incidents to the repository maintainer, `@himanshu748`, in the
affected thread when doing so is safe. For a private report, use a contact
method published on [the maintainer's GitHub profile](https://github.com/himanshu748).
Do not post sensitive details publicly. If no private route is available,
request one without including the incident details.

The maintainer will assess reports in context and protect privacy where
possible. Responses can include a request to change behavior, removal of
content, a warning, or temporary or permanent exclusion from project spaces.
Decisions should be proportionate to impact and repeated behavior. Someone
involved in a report should not decide their own case; an independent reviewer
should be sought where available. This small project cannot promise a response
deadline or an independent moderation team.
